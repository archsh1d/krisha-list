# Krisha List

**Тіл:** [Русский](README.md) · [English](README.en.md) · **Қазақша**

Krisha List — Krisha.kz сайтындағы үй, саяжай және пәтер сату жөніндегі HTML іздеу нәтижелерін талдауға арналған тәуелсіз зерттеу құралы. Жобаға жергілікті интерфейс, аумақ картасы, SQLite каталогы, CSV/JSONL экспорты және серверлік API кіреді. Репозиторийде **тек код пен жасанды тест деректері** бар. Нақты хабарландырулар, бет көшірмелері, дерекқорлар мен құпия кілттер оған кірмейді. Бұл Kolesa немесе Krisha.kz компаниясының ресми сервисі емес.

> **Әр пайдаланушы жеке рұқсат алуы керек.** [Krisha.kz келісімінің](https://krisha.kz/content/special/agreement) 5.3-тармағына сәйкес автоматты қолжетімділік пен материалдарды алу үшін Kolesa компаниясының жазбаша рұқсаты қажет. Автордың немесе басқа инстанция иесінің рұқсаты осы репозиторийді пайдаланушыларға берілмейді. Өз рұқсатыңыздың қатынау тәсілін, көлемін, сақтауды және деректерді кейінгі пайдалануды қамтитынын тексеріңіз.

## Docker Compose арқылы жылдам іске қосу

Docker, Docker Compose және Python орнатыңыз. Репозиторийдің түбірлік қалтасында:

```sh
python scripts/init_env.py
docker compose up --build -d
docker compose ps
```

`http://127.0.0.1:8765/` мекенжайын ашыңыз. Сервис тек осы компьютерде қолжетімді, **тікелей жинау әдепкіде өшірулі**. Жасанды мысалды көруге немесе бұрын сақталған HTML файлыңызды импорттауға болады. Kolesa компаниясының жеке жазбаша рұқсатын алғаннан кейін ғана жеке `.env` файлында `KRISHA_ENABLE_LIVE=1` мәнін орнатып, контейнерді қайта іске қосыңыз:

```sh
docker compose up -d --force-recreate
```

Тексеру, деректерді сақтау, резервтік көшіру және Docker қолданбай іске қосу туралы [орнату нұсқаулығын](docs/kk/deployment.md) қараңыз.

## Сервис мүмкіндіктері

Интерфейс пен API бетінде орыс, ағылшын және қазақ тілдерін ауыстыруға болады; таңдау браузерде сақталады. Жиналған хабарландыру мәтіні бастапқы тілінде қалады.

- Негізгі HTML нәтижелер тізімін және карта тізімінің JSON деректерін оқып, координаталарды хабарландыруларға ID бойынша байланыстырады.
- Қала, аудан/шағынаудан атауы немесе картада сызылған аумақ бойынша жинауды шектейді. Еркін енгізілген атау жүктелген хабарландыру мекенжайларымен салыстырылады.
- Хабарландыруларды, баға өзгерістерін және іске қосу тарихын SQLite-та сақтайды; жергілікті деректерді CSV/JSONL пішіміне экспорттайды.
- Bearer токені бар жергілікті `/api/v1` және [OpenAPI сипаттамасын](web/dist/openapi.kk.json) ұсынады.

## Нәтижелерге әсер ететін шектеулер

Тікелей жинау нәтижелердің толықтығы мен өзектілігіне кепілдік бермейді. Krisha.kz HTTP 468 қайтаруы, HTML құрылымын өзгертуі немесе қолжетімділікті шектеуі мүмкін; жинағыш тексеруді айналып өтпей тоқтайды. Қайталанған сұрау **жаңа беті жоқ ескі көшірмені** көрсетуі мүмкін. Координатасы жоқ хабарландырулар полигон іріктемесіне кірмейді, ал картадағы орын жуық болуы мүмкін. Ескі HTML файлын импорттау уақыты оның ішіндегі деректердің жаңа екенін дәлелдемейді. [Барлық шектеулерді](docs/kk/limitations.md) оқыңыз.

Ішкі HTTP сервері зерттеу инстанциясына арналған. Compose тек `127.0.0.1` мекенжайында жариялайды; **оны Интернетке тікелей шығармаңыз**. Желілік API қолжетімділігі үшін бөлек қорғалған шлюз, HTTPS, шектеулер және токендерді басқару қажет. [Қауіпсіздік](SECURITY.kk.md) бөлімін қараңыз.
