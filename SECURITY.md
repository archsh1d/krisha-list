# Безопасность исследовательского экземпляра

**Язык:** **Русский** · [English](SECURITY.en.md) · [Қазақша](SECURITY.kk.md)

По умолчанию Docker Compose привязывает порт к `127.0.0.1` и отключает живой
сбор. Внутренний Python HTTP-сервер не рассчитан на прямой публичный доступ.
Не меняйте привязку порта на `0.0.0.0` без защищённого шлюза, HTTPS,
аутентификации, ограничений запросов/ресурсов и мониторинга.
При сетевой интеграции публикуйте через шлюз только нужные маршруты
`/api/v1/*`. Локальные маршруты интерфейса и импорта (`/`, `/api/catalog`,
`/api/collect`, `/api/import-html` и другие вне `/api/v1/*`) не имеют
отдельной аутентификации; проверка HTTP-заголовков не заменяет ограничение
доступа на шлюзе.

Храните `.env`, SQLite, HTML/JSON-снимки, CSV и резервные копии вне Git. Если
токен раскрыт, сгенерируйте новый приватный `.env` или замените токен и
перезапустите контейнер; старый токен перестанет работать. Один общий токен
на экземпляр подходит только для контролируемой исследовательской среды.

При сообщении об уязвимости не публикуйте секреты или реальные объявления в
открытом issue. Свяжитесь с владельцем развёрнутого экземпляра по его
закрытому каналу связи. У проекта пока нет публичного адреса для security
reports; до его появления не публикуйте приватные данные в репозитории.
