# Ограничения, разрешения и интерпретация данных

**Язык:** **Русский** · [English](en/limitations.md) · [Қазақша](kk/limitations.md)

## Доступ к источнику

Согласно п. 5.3 [пользовательского соглашения Krisha.kz](https://krisha.kz/content/special/agreement),
для автоматического доступа и извлечения материалов требуется письменное
разрешение Kolesa. Пункты 5.5.6–5.5.7 касаются копирования, распространения
информации и работы защитных систем. Каждый оператор должен получить и
проверить **своё** разрешение и его технические условия. Публикация этого кода
не предоставляет разрешения на сбор или дальнейшее распространение объявлений.

Сервис не решает CAPTCHA, не обходит страницу проверки доступа, не применяет
прокси для обхода ограничений и не получает контакты продавцов. HTTP 403/429/468
или страница SafeLine останавливают сбор. Паузы и повторное использование
снимков снижают число запросов, но не гарантируют доступ.

## Полнота

- `complete` означает завершение доступной пагинации данного запроса; это не
  доказательство, что источник показал **все** существующие объявления.
- `limited` означает остановку по выбранному числу страниц. `partial` означает
  прерванный или неполный результат. `cached` означает старый сохранённый снимок;
  число новых страниц равно нулю.
- Поиск произвольного названия района/микрорайона фильтрует уже полученные
  городские страницы по адресу. При ограничении числа страниц результат может
  пропустить подходящие объекты.
- Для полигона используется ограничивающий прямоугольник источника, затем
  точная фильтрация точек карты. Карточки без координат исключаются. Если карта
  ответила с ошибкой, сбор по области отмечается как неполный.
- Координаты взяты из списка карты Krisha.kz и могут быть приблизительными;
  они не подтверждают кадастровые границы и точный адрес объекта.

## Актуальность и качество

Каталог хранит ранее увиденные объявления и не доказывает, что они остаются
активными. `first_seen_at` и `last_seen_at` — время наблюдения инструментом,
а не публикации объявления. При импорте HTML оно отражает время **импорта**;
возраст исходного файла может быть неизвестен. Импорт не заменяет поля уже
сохранённой карточки, чтобы старый файл не откатил более свежую цену.

«Цена объекта / сот.» — цена **всего дома с участком**, разделённая на площадь
участка, а не оценка стоимости земли. Объявления заполняются пользователями
источника; значения могут отсутствовать или быть неточными. Парсер зависит от
HTML-разметки выдачи и должен проверяться после изменений сайта.

Сохранённые реальные HTML, JSON, SQLite, CSV и ключи содержат данные и не
входят в публичный Git-репозиторий. Синтетические фикстуры предназначены только
для тестов.
