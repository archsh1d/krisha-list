# Krisha List: интерфейс және консоль

**Тіл:** [Русский](../usage.md) · [English](../en/usage.md) · **Қазақша**

## Веб-интерфейс

Алдымен [орнату нұсқаулығын](deployment.md) оқыңыз. [Бұрынғы жеке демо-нұсқаға](https://krisha-list-workbench-20261114.fruitfulflask8.chatgpt.site) кіру үшін ChatGPT жүйесіне кіру қажет; ол импортталған деректерді браузерде сақтайды. Жергілікті интерфейс хабарландыруларды, баға мен іске қосу тарихын SQLite-та сақтайды, ал CSV файлын жергілікті API арқылы жасайды. Жарияланған статикалық сайт Krisha.kz сайтына сұрау жібермейді. Ондағы «Хабарландыруларды жинау» батырмасы таңдалған санатты, орынды, полигонды және сүзгілерді `127.0.0.1:8765` мекенжайындағы жинағышқа береді; жинауды бастау үшін жергілікті бетте батырманы қайта басыңыз.

Үйлер/саяжайлар немесе пәтерлерді, қаланы және аудан/шағынаудан атауын не картадағы аумақты таңдаңыз. Ұсыныстарда белгілі Krisha.kz бөлімдері мен сақталған мекенжайлар бар. Белгілі бөлім тікелей сұралады. Еркін атау жүктелген қала беттеріндегі мекенжайлармен салыстырылады; бет шегі сәйкес нысандарды өткізіп жіберуі мүмкін. «Барлық беттер» қолжетімді беттерді аралайды, бірақ дереккөздің бас тартуы оны тоқтатуы мүмкін. Таңдалған шарт каталогқа, жиынтыққа, картаға және CSV экспортына да қолданылады.

Үлкен редакторды ашу үшін «Картада аумақты сызу» батырмасын басыңыз. «Қайта сызу» таңдап, кемінде үш нүкте белгілеңіз де, сақтаңыз. Нүктені алып тастауға, контурды тазалауға, картаны жылжытуға және масштабтауға болады. Бас тарту немесе картаны жабу бұрынғы аумақты сақтайды; «Аумақты жою» оны өшіреді. Балама ретінде солтүстік ендік, батыс бойлық, оңтүстік ендік, шығыс бойлық ретімен тікбұрыш енгізіңіз. Аумақ браузерде сақталады. Полигон бойынша жинағыш алдымен оның қамтушы тікбұрышын сұрап, кейін нақты контур ішіндегі карта нүктелерін қалдырады. Координатасы жоқ карточкалар алынып тасталады. Жиынтықта белсенді аумаққа сәйкестігін тексеру мүмкін емес карточкалар саны көрсетіледі.

Каталогта кесте, карта, санат пен нысан түрінің сүзгілері, сұрыптау және CSV экспорты бар. Жиынтық соңғы бақылау күнін және баға көрсеткіштерін көрсетеді. «Нысан бағасы / сотық» — үй мен жердің толық бағасын жер аумағына бөлу; бес нысаннан аз топтарда медиана көрсетілмейді. Картадағы орын жуық болуы мүмкін. Нысан жолында координаталар, OpenStreetMap сілтемесі және баға өзгерістері беріледі. «Барлық беттер» келесі бет сілтемелерін соңына дейін қарайды, бірақ дереккөз қатесі нәтижені толық емес қалдыруы мүмкін.

Дәл сол параметрлермен 15 минут ішінде қайталанған сұрау жаңа желілік сұраусыз сақталған көшірмені қолданады. HTTP 403/429/468 немесе HTTP 200 мәртебесімен келген қолжетімділікті тексеру бетінен кейін жалпы 30 минуттық үзіліс қолданылады; интерфейс келесі әрекет уақытын және бар болса бұрынғы көшірмені көрсетеді. Әр желілік жауаптан кейін, карта сұрауларын қоса, келесі сұрауға дейін кемінде үш секунд күтеді. Бұл сұрау жиілігін азайтады, бірақ HTTP 468 болмауына кепіл емес. `cached` нәтижесінде жаңа бет саны нөл; ол хабарландырулар мен бағалардың қазіргі күйін растамайды.

Тікелей жинауды тек **Kolesa компаниясының жазбаша рұқсатымен** тексеру үшін репозиторий түбірінен іске қосыңыз:

```powershell
.venv\Scripts\python -m krisha_list serve --enable-live --db data/krisha.sqlite3
```

`http://127.0.0.1:8765/` ашыңыз. Жергілікті сервер хабарландырулар мен карта координаталарын SQLite-та, алынған HTML/JSON жауаптарын `data/snapshots/` ішінде сақтайды. HTML импорты да SQLite-қа жазылады. Бірінші ашқанда браузердегі бұрын сақталған нақты карточкалар базаға көшіріледі, бірақ жаңарақ жазбаларды алмастырмайды. Журнал параметрлерді, бет пен нысан санын, аумақтан шығарылғандарды, HTTP мәртебесін және тоқтау себебін тіркейді. `complete` беттер аяқталғанын білдіреді; `limited`, `partial` және `cached` қазіргі толық деректерді білдірмейді.

Баға, бөлме және басқа Krisha.kz сүзгілерін қолдану үшін іздеу нәтижелерінің HTTPS сілтемесін URL өрісіне енгізіңіз. Сілтеменің сүзгілері сақталады, ал таңдалған қала мен аумақ оның орналасуын алмастырады. Сілтеме санаты санат таңдағышынан басым.

## Әзірлеушілерге арналған API

Нұсқаланған серверлік API `/api/v1` мекенжайында. Жарияланған статикалық сайтта [қысқаша API нұсқаулығы](https://krisha-list-workbench-20261114.fruitfulflask8.chatgpt.site/api.html) және [OpenAPI 3.1](../../web/dist/openapi.kk.json) бар, бірақ ол сіздің SQLite каталогыңызды жарияламайды және жинауды бастамайды. Деректерге өзіңіз іске қосқан сервер арқылы қол жеткізіңіз.

Токенді бір рет жасап, серверді іске қосыңыз:

```powershell
.venv\Scripts\python -c "import secrets; from pathlib import Path; Path('data/api-token.txt').write_text(secrets.token_urlsafe(32), encoding='utf-8')"
.venv\Scripts\python -m krisha_list serve --enable-live --api-token-file data/api-token.txt
```

Баламасы — кемінде 32 таңбалы `KRISHA_API_TOKEN`. Оны URL, браузер JavaScript коды немесе Git ішіне қоспаңыз. API `Authorization: Bearer <token>` қабылдайды және `Origin` тақырыбы бар сұрауларды кері қайтарады; серверлік клиент пайдаланыңыз. Желілік қолжетімділік үшін `--host 0.0.0.0` токен мен HTTPS проксиді талап етеді. Ескі интерфейс маршруттары тек жергілікті қолжетімді.

Маршруттар: `GET /api/v1/status`, `GET /api/v1/listings`, `GET /api/v1/listings/{id}`, `GET /api/v1/runs`, `GET /api/v1/runs/{id}`, `POST /api/v1/collections` және ашық `GET /api/v1/openapi.json`. Тізім сүзгілері: `category`, дәл `city` және `district`, `bounds` (солтүстік, батыс, оңтүстік, шығыс), `updated_after` (уақыт белдеуі бар ISO 8601), `limit` (1–100), `offset`. Жауапта `data`, `page.total`, `page.next_offset` болады; жеке карточкада баға тарихы бар. Оқу кезінде жаңа жинау каталогты өзгертсе, `offset` беттері жылжуы мүмкін.

`POST /api/v1/collections` маршруты `url`, `max_pages`, `bounds`, `polygon`, `location_query` қабылдайды. Ол синхронды; байланыс үзілсе, `/api/v1/runs` арқылы тексеріңіз. Сол кідірістер, көшірме кэші, қатар жинаудан қорғау және HTTP 468 кезінде тоқтау API ішінде де қолданылады. Маршрут үшін `--enable-live` және дереккөз рұқсаты керек.

PowerShell арқылы алғашқы 50 үйді оқу мысалы:

```powershell
$token = (Get-Content data/api-token.txt -Raw).Trim()
Invoke-RestMethod -Uri 'http://127.0.0.1:8765/api/v1/listings?category=house&limit=50' -Headers @{ Authorization = "Bearer $token" }
```

[API толық нұсқаулығын](api.md) және [қазақша OpenAPI сипаттамасын](../../web/dist/openapi.kk.json) қараңыз.

## Консоль құралы

Жинағыш үй, саяжай және пәтер сатудың **негізгі HTML нәтижелер тізімін** оқиды; «Ыстық ұсыныстар» блогын қоспайды. Нысандарды ID бойынша жаңартады және баға өзгерсе тарихқа оқиға қосады. Әр бет үшін тиісті карта тізімінің JSON жауабын сұрап, координаталарды ID бойынша байланыстырады. Нәтиже мен карта беттері ығысса, келесі карта бетін де тексереді. `geo_source=krisha_map_list` сайт көрсеткен орынды білдіреді; ол нақты жер телімі немесе кіреберіс болмауы мүмкін. Карта координата бермесе өрістер бос қалады; уақытша бос жауапта бұрынғы координаталар сақталады.

Жоба жеке хабарландыру беттерін ашпайды, сатушылардың байланысын жинамайды және қолжетімділік тексеруін айналып өтпейді. HTML құрылымы өзгерсе немесе қорғау беті келсе, жинау тоқтайды.

### Орнату

Python 3.11 немесе жаңарақ нұсқа қажет. Жоба қалтасында PowerShell арқылы:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e .
.venv\Scripts\python -m krisha_list --help
```

### Сақталған беттерді пайдалану

```powershell
.venv\Scripts\python -m krisha_list parse-file page.html
.venv\Scripts\python -m krisha_list stats
.venv\Scripts\python -m krisha_list export --output listings.csv
.venv\Scripts\python -m krisha_list export --table price_history --format jsonl --output prices.jsonl
```

Файл басқа іздеу бетіне тиесілі болса, дұрыс бет нөмірі мен пагинация үшін сол мекенжайды `--url` арқылы беріңіз.

### Рұқсат болғанда жинау

```powershell
.venv\Scripts\python -m krisha_list collect
.venv\Scripts\python -m krisha_list collect --url "https://krisha.kz/prodazha/doma-dachi/almaty-almalinskij/" --max-pages 2 --db data/krisha.sqlite3
.venv\Scripts\python -m krisha_list collect --url "https://krisha.kz/prodazha/kvartiry/almaty-almalinskij/" --max-pages 2 --db data/krisha.sqlite3
.venv\Scripts\python -m krisha_list export --db data/krisha.sqlite3 --category apartment --output apartments.csv
.venv\Scripts\python -m krisha_list collect --max-pages 1 --db data/probe.sqlite3 --snapshot-dir data/snapshots/probe
```

Аумақты шектеу үшін `--bounds` мәнін ондық градуспен `north,west,south,east` ретімен беріңіз:

```powershell
.venv\Scripts\python -m krisha_list collect --url "https://krisha.kz/prodazha/doma-dachi/almaty-almalinskij/" --bounds "43.255,76.87,43.24,76.91" --max-pages 2 --db data/krisha.sqlite3
.venv\Scripts\python -m krisha_list export --db data/krisha.sqlite3 --bounds "43.255,76.87,43.24,76.91" --output area.csv
```

`collect` шекараны Krisha.kz нәтижелеріне беріп, сақтар алдында әр карточканың координатасын тексереді. Карта нүктесі жоқ немесе тікбұрыштан тыс карточкалар алынбайды. `--url` ішінде бар `bounds` та ескеріледі. `export --bounds` жергілікті базаны сүзеді және `--category` параметрімен бірге жұмыс істейді. Аумақ бойынша жинауда `--no-geo` қолжетімсіз. Карта координатасы жуық болуы мүмкін, сондықтан шекара заңды жер шекарасына емес, картадағы нүктеге қатысты.

`--max-pages` болмаса, пәрмен «Келесі» сілтемесімен тізім соңына дейін өтеді. Беттер арасындағы әдепкі кідіріс — үш секунд. HTTP 403/429/468 жинауды тоқтатады. SafeLine тексеру беті келсе, жергілікті API бұл туралы хабарлап, мәртебе мен URL бар `source-error.json` және диагностикаға арналған `source-response.html` сақтайды. Прокси немесе өзге айналып өту тәсілдері жобаға кірмейді. `--snapshot-dir` алынған HTML мен карта JSON жауабын сақтайды; аумақ таңдалмаған кезде `--no-geo` карта сұрауын өшіреді. Карта қатесі қорытынды JSON ішіндегі `geo_errors` өрісіне жазылады, ал HTML жинау жалғасады.

### Деректер

`listings` ішінде ID, `/a/show/<id>` канондық сілтемесі, тақырып, нысан түрі мен санаты, бөлме саны, теңгемен баға, аудан, мекенжай, карта орны, қысқаша сипаттама, сатушы түрі, қала және бастапқы сайттағы күн белгісі сақталады. Үйлерде үй мен жер ауданы, пәтерлерде пәтер ауданы, қабат, ғимарат қабаты және тұрғын үй кешені болуы мүмкін. Салынған жыл сипаттамада бар болса алынады. `price_history` бастапқы баға мен кейінгі өзгерістерді UTC бақылау уақытымен сақтайды. `first_seen_at`, `last_seen_at` — жариялау емес, жинағыш бақылауының уақыты. Карточкадағы күнде жыл болмауы мүмкін; бастапқы мәтін сақталады. HTML ішінде жоқ өрістер базада бос қалады. Бір толық емес өтумен сайттан жойылғанын анықтау мүмкін емес. CSV және JSONL тек жергілікті базадан экспортталады, желілік сұрау жасалмайды.

## Тексеру және дереккөзге қолжетімділік

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
```

Тесттер жасанды HTML қолданады. [Бұрынғы тікелей тексеру есебі](live-test-2026-11-14.md) 2026 жылғы 14 қарашадағы нәтижені сипаттайды; сайт өзгерсе, парсерді жаңарту қажет болуы мүмкін. Кейінгі тексеруде жеті беттегі 133 хабарландыруға 133 карта нүктесі табылды; пәтерлердің бірінші бетінде 23 карточка, оның 20-сында карта нүктесі болды. Бұл сандар өзгеруі мүмкін, ал жарнамалық карточканың карта тізімінде жұбы болмауы ықтимал.

[Krisha.kz келісімі](https://krisha.kz/content/special/agreement) автоматты кіру мен хабарландыруларды алу үшін Kolesa компаниясының жазбаша рұқсатын талап етеді. `collect` пәрменін тек сол рұқсатпен пайдаланыңыз. Жергілікті `parse-file` сіздегі HTML құрылымын сайтқа сұрау жібермей тексереді.
