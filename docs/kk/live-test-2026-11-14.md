Жер ауданы жоқ үш карточканың бастапқы нәтиже тақырыбында бұл мәлімет болмаған. Сақталған жеті HTML файлын қайта талдау тағы да 133 бірегей ID берді. Соңғы бетте «Келесі» сілтемесі болмады.

Жеті HTML файлын жергілікті веб-нұсқаға импорттау 133 нақты хабарландыруды көрсетті. Бұрын екі демо жазбаның нақты деректермен араласқаны анықталып, түзетілді; қайта импорттан кейін 133 жазба қалды, демо жазба болмады. Бір бетке жасалған жергілікті тікелей тексеру 20 хабарландыру алды, базадағы 133 ID сақталды және жалған баға өзгерісі тіркелмеді.

Көшірмелер мен база тек жергілікті `data/` қалтасында сақталып, Git-тен шығарылған. Сандар — тексеру кезіндегі тарихи байқау, дереккөздің тұрақты мәні емес.
