# Шектеулер, рұқсат және деректерді түсіндіру

**Тіл:** [Русский](../limitations.md) · [English](../en/limitations.md) · **Қазақша**

## Дереккөзге қолжетімділік

[Krisha.kz келісімінің](https://krisha.kz/content/special/agreement) 5.3-тармағына сәйкес автоматты кіру мен материалдарды алу үшін Kolesa компаниясының жазбаша рұқсаты қажет. 5.5.6–5.5.7-тармақтар көшіруге, ақпаратты таратуға және қорғаныс жүйелеріне қатысты. Әр оператор **өз рұқсатын** және оның техникалық шарттарын алып, тексеруі тиіс. Кодты жариялау хабарландыруларды жинауға немесе таратуға рұқсат бермейді.

Сервис CAPTCHA шешпейді, қолжетімділікті тексеру беттерін айналып өтпейді, шектеулерді айналып өту үшін прокси қолданбайды және сатушылардың байланыс деректерін алмайды. HTTP 403/429/468 немесе SafeLine тексеруі жинауды тоқтатады. Кідірістер мен сақталған көшірмені қайта пайдалану сұраулар санын азайтады, бірақ қолжетімділікке кепілдік бермейді.

## Толықтық

- `complete` белгілі сұраудың қолжетімді беттері аяқталғанын білдіреді; дереккөз **барлық** хабарландыруды көрсетті деген дәлел емес.
- `limited` таңдалған бет шегіне жеткенін, `partial` үзілген немесе толық емес нәтижені білдіреді. `cached` — нөл жаңа беті бар бұрынғы сақталған көшірме.
- Еркін аудан/шағынаудан атауы алынған қала беттеріндегі мекенжайларға қолданылады. Бет санын шектеу сәйкес нысандарды өткізіп жіберуі мүмкін.
- Полигон үшін әуелі дереккөздің қамтушы тікбұрышы, кейін картаның нүктелері бойынша нақты сүзгі қолданылады. Координатасы жоқ хабарландырулар алынып тасталады. Карта қатесі аумақ нәтижесін толық емес етеді.
- Координаталар Krisha.kz картасының тізімінен алынады және жуық болуы мүмкін. Олар кадастрлық шекараны немесе нақты мекенжайды растамайды.

## Өзектілік және сапа

Каталогта бұрын байқалған хабарландырулар сақталады; бұл олардың әлі белсенді екенін дәлелдемейді. `first_seen_at` пен `last_seen_at` — жарияланған уақыт емес, құралдың бақылау уақыты. Импортталған HTML үшін ол **импорт уақытын** көрсетеді; бастапқы файлдың жасы белгісіз болуы мүмкін. Ескі файл жаңа бағаны кері өзгертпеуі үшін импорт сақталған карточканың өрістерін қайта жазбайды.

«Нысан бағасы / сотық» — **үй мен жердің толық бағасын** жер аумағына бөлу; бұл жердің жеке бағасы емес. Хабарландыру мәндерін дереккөз пайдаланушылары енгізеді, сондықтан өрістер болмауы немесе дәл болмауы мүмкін. Парсер іздеу бетінің HTML құрылымына тәуелді; сайт өзгергеннен кейін оны тексеру қажет.

Нақты HTML, JSON, SQLite, CSV және құпиялар ашық Git-ке кірмейді. Жасанды үлгілер тек тестке арналған.
