# Интеграцияға арналған API

**Тіл:** [Русский](../api.md) · [English](../en/api.md) · **Қазақша**

Жергілікті сервер `/api/v1/status`, `/api/v1/listings`, `/api/v1/listings/{id}`, `/api/v1/runs`, `/api/v1/runs/{id}` және синхронды `POST /api/v1/collections` маршруттарын ұсынады. Толық схеманы [OpenAPI 3.1 сипаттамасынан](../../web/dist/openapi.kk.json) қараңыз.

Іске қосылған сервер аударылған спецификацияны `/api/v1/openapi.json?lang=kk` (немесе `?lang=en`) мекенжайында береді; әдепкі тіл — орысша.

API серверлік клиенттерге арналған. Bearer токенін **әр инстанцияның иесі** өзі жасап, сақтайды. `python scripts/init_env.py` Docker Compose үшін токен жасайды. Docker қолданбасаңыз, `KRISHA_API_TOKEN` немесе `--api-token-file` пайдаланыңыз. Жергілікті токенді Kolesa бермейді және ол деректер жинауға рұқсат болып саналмайды. Оны Git-ке немесе браузердің JavaScript кодына жарияламаңыз.

`POST /collections` үшін тікелей жинау қосылған және дереккөздің рұқсаты болуы керек. Сұрау синхронды орындалады, сондықтан ұзақ айналым клиенттің күту мерзімінен асып кетуі мүмкін. Байланыс үзілсе, `/runs` арқылы күйді тексеріңіз. `max_pages=0` қолжетімді беттерді қарауды білдіреді, бірақ HTTP шектеуі оны ертерек тоқтатуы мүмкін. `cached=true` нәтижесі бұрынғы көшірмеден алынады; `pages=0` жаңа бет жоқ екенін білдіреді. `cached_at`, `source_status`, `geo_errors` және іске қосу тарихын тексеріңіз.

`reused_coordinates` дәл сол параметрлермен жасалған, алты сағаттан аспаған толық көшірмеден қайта қолданылған карта нүктелерін санайды.

`GET /listings` санат, дәл қала және аудан атауы, тікбұрышты `bounds`, `updated_after`, `limit` және `offset` сүзгілерін қолдайды. Оқу кезінде каталог өзгерсе, `offset` беттерінің құрамы жылжуы мүмкін. Бірізді экспорт үшін жинауды тоқтатыңыз немесе алдымен SQLite резервтік көшірмесін жасаңыз.

Қазіргі нұсқада **әр инстанцияға бір токен** қолданылады; рөлдер, жарамдылық мерзімі және жеке квоталар жоқ. Оны тәуелсіз әзірлеушілерге таратпаңыз. Ашық көппайдаланушылық API үшін бөлек шлюз және қолжетімділікті басқару қажет; [қауіпсіздік](../../SECURITY.kk.md) бөлімін қараңыз.
