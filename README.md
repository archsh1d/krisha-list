# Krisha List

Исследовательский инструмент для разбора HTML-выдачи продажи домов, дач и квартир
Krisha.kz. Включает локальный интерфейс, карту областей, SQLite-каталог,
экспорт CSV/JSONL и серверный API. Репозиторий содержит **код и синтетические
тестовые данные**; реальные объявления, снимки страниц, база и ключи в него не
входят. Это независимый проект, не официальный сервис Kolesa/Krisha.kz.

> **Разрешение требуется каждому оператору отдельно.** Пункт 5.3
> [соглашения Krisha.kz](https://krisha.kz/content/special/agreement)
> требует письменного разрешения Kolesa для автоматического доступа и извлечения
> материалов. Разрешение автора/владельца одного экземпляра не передаётся
> пользователям этого репозитория. Проверьте, что ваше разрешение покрывает
> выбранные способы доступа, объём, хранение и дальнейшее использование данных.

## Быстрый запуск через Docker Compose

Нужны Docker, Docker Compose и Python для создания локального токена. Из корня
клонированного репозитория:

```sh
python scripts/init_env.py
docker compose up --build -d
docker compose ps
```

Откройте `http://127.0.0.1:8765/`. По умолчанию сервис доступен только на
этом компьютере, **живой сбор отключён**. Можно открыть синтетический пример
или импортировать свой ранее сохранённый HTML. Для автоматического доступа
сначала получите своё письменное разрешение Kolesa, затем задайте
`KRISHA_ENABLE_LIVE=1` в приватном `.env` и перезапустите контейнер:

```sh
docker compose up -d --force-recreate
```

Подробности, проверка состояния, хранение данных, резервное копирование и
запуск без Docker: [развёртывание](docs/deployment.md).

## Что делает сервис

- Читает основную HTML-выдачу и соответствующий JSON списка карты; связывает
  точки с объявлениями по ID.
- Позволяет ограничить сбор городом, названием района/микрорайона или областью
  на карте. Для произвольного названия применяет фильтр к полученным карточкам.
- Сохраняет карточки, изменения цен и журнал запусков в SQLite; экспортирует
  сохранённые данные в CSV/JSONL.
- Предоставляет локальный `/api/v1` с Bearer-токеном и
  [описанием OpenAPI](web/dist/openapi.json).

## Важные ограничения

Живой сбор не гарантирует полноту и свежесть. Krisha.kz может вернуть HTTP 468,
изменить разметку или ограничить доступ; сервис останавливается, не пытаясь
обходить проверку. Повторный запрос может показать **старый снимок с нулём
новых страниц**. Объявления без координат не входят в выборку по полигону;
позиция карты может быть приблизительной. При импорте старого HTML дата импорта
не доказывает актуальность объявления. [Полный перечень ограничений](docs/limitations.md).

Локальный HTTP-сервер предназначен для исследовательского экземпляра. Compose
публикует только `127.0.0.1`; **не выставляйте его напрямую в Интернет**.
Для сетевого доступа к API потребуются отдельный защищённый шлюз, HTTPS,
лимиты и управление токенами: [безопасность](SECURITY.md).
